When Reporting a Problem

To help identify an issue, include useful non-sensitive information such as:

  • ✓ A clear description of what happened.
  • ✓ The page or feature where the issue occurred.
  • ✓ Relevant screenshots when appropriate.
  • ✓ Steps that can reproduce the issue.

Never Send Sensitive Secrets

Apex Network support should never require your wallet seed phrase, private key or account password.

  • ✕ Never send a seed phrase.
  • ✕ Never send a private key.
  • ✕ Never send passwords or login codes.
  • ✕ Never send recovery codes.
