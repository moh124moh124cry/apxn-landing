APXN Network Shares Infrastructure Migration Progress and Verified Points Level Updates

APXN Network reports completion of Cloudflare migration for key services while preserving user data and details the seven-tier reward structure based on verified points along.

Apex Network Editorial • November 15, 2026 • 6 min read
Original APXN link copied

The APXN Network development team completed an important milestone by migrating the official website, APXN Blog, mining application, and Telegram bot from Vercel to Cloudflare. The migration preserved users balances and maintained access to mining, referrals, rewards, and daily tasks. Services were tested to confirm correct responses before old Vercel projects were removed. Cloudflare analytics recorded approximately 30,000 total requests over a 24-hour period with no Worker execution errors. This step supports continued technical infrastructure growth for the project. The team also announced an update to the seven-level reward system based exclusively on verified APXN points. All levels are determined by these points and the reward allocation remains available to eligible users.

Level five covers one hundred fifty thousand to two hundred forty nine thousand nine hundred ninety nine verified points. Community Allocation and Growth Period

Sixty three million APXN are allocated to the community through the seven-level system. Distribution occurs proportionally to verified APXN points held within each level. The verified points reward stays available to all eligible users without a limit on the number of recipients. This allocation supports ongoing participation across the network as the global community expands. The project continues to focus on infrastructure that sustains activity during the current growth period.

The migration of services to Cloudflare forms part of efforts to strengthen technical foundations. Continued activity across APXN services was observed after the changeover. The team views the completed migration as preparation for future development phases. Network participants can expect the level system to remain the primary method for determining reward eligibility. These updates reflect steady progress in both infrastructure and community reward mechanics during the monitored period.

Application Migration Planning and Testing Setup

The team began migrating the APXN Telegram mining application from Vercel to Cloudflare. The goal included improving performance and reducing resource consumption while preserving user data and existing functionality. An independent testing environment named apxn-miner-preview was created and connected through the cloudflare-migration branch. The official version used by the community remained unchanged during this preparation phase. Build and authentication issues were resolved before further steps were taken.

After the test environment was ready the application launched inside Telegram using a separate test bot. The deployment of apxn-miner-live was prepared to verify readiness before any official project URL update. A gradual migration approach was planned after confirming that essential application functions operate correctly. This sequence allowed the team to evaluate the new hosting environment without affecting the live community instance. The process focused on maintaining continuity throughout the transition stages.

Separate Test Deployment and Function Verification

The test application successfully launched inside Telegram using a dedicated test bot. Testing confirmed that balances, referrals, active days, mining status, and boosts matched between the Cloudflare and Vercel versions. The tasks, upgrades, and project information sections also displayed correctly during the evaluation. A few daily task links required additional configuration that was scheduled for later completion. The separate test environment allowed isolated verification of core features before any broader rollout.

Following the successful testing phase the team prepared a separate Cloudflare deployment for the official application. The new deployment was created under the name apxn-miner-live and connected to the GitHub repository. Necessary build and runtime environment variables were configured as part of the setup. The Cloudflare test application continued to run while the official deployment remained in preparation. Users had not yet been migrated at the time of the reported status update.

Official Deployment Preparation and Current Status

The new deployment intended for the official application is being prepared on Cloudflare. The Cloudflare test application is running successfully while final steps for the official instance continue. The official Telegram application, bot, and webhook remain operational on Vercel without any changes. The next phase involves completing the build and runtime configuration for the live deployment. This staged approach keeps the community version stable during the transition period.

The project maintains focus on ensuring that the official application functions correctly before any user migration occurs. The separate test bot and preview environment provided a controlled setting for validation. All essential application functions were checked during the test phase. The team continues to monitor the Cloudflare deployment as it moves toward the official release. This preparation supports the long-term goal of hosting the application on the new infrastructure.
