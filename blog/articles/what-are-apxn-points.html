What Are APXN Points? How the Apex Network Telegram Mini App Works

A transparent guide to the current APXN ecosystem point system, including 12-hour claims, daily check-ins, social tasks, referrals and mining-speed boosts.

Apex Network Editorial • September 8, 2026 • 8 min read

Quick answer

APXN Points are the current in-app ecosystem points tracked by the Apex Network Telegram Mini App. Users can accumulate them through timed claims, daily check-ins, verified social tasks and referrals. They should not be presented as guaranteed cash value or as a guaranteed number of future tokens.

Apex Network is building its user experience around a Telegram Mini App, allowing people to participate directly from Telegram without installing a separate mobile application. At the center of that experience is the APXN Points system.

The most important thing to understand is that the current balance shown inside the Mini App represents ecosystem points and pre-launch rewards. These points are used to measure participation before later stages of the Apex Network roadmap. They should not be confused with a guaranteed cash balance, guaranteed investment return or guaranteed future token allocation.

This article explains how the system currently works based on the live application logic, and separates features that are already active from features that remain planned for future development.

What exactly are APXN Points?

APXN Points are digital participation units recorded in the Apex Network application database. They help track a user's activity in the ecosystem, including mining sessions, check-ins, tasks and referrals.

In practical terms, the user opens the Telegram Mini App, starts or continues a mining session, returns after the required time window and claims the accumulated amount. Other activities can add additional points or affect the rate at which the balance grows.

Important distinction

The current app tracks APXN Points. The points system should not be described as a guaranteed exchange-listed token balance, guaranteed withdrawal amount or guaranteed future market value.

How the 12-hour APXN claim cycle works

The current Mini App uses a 12-hour claim cycle. During this period, the app calculates the points accumulated from the user's mining rate. When the claim window is ready, the user can claim the accumulated amount and begin the next cycle.

This system is designed around recurring participation rather than continuous interaction. A user does not need to keep Telegram open for 12 hours. Instead, the application uses timestamps and account data to determine how much has accumulated.

The current base mining rate in the application logic is:

Base Rate
0.00025 APXN Points / second

Because the system is driven by recorded time and a defined rate, the balance can be calculated when the user returns. This is different from traditional proof-of-work cryptocurrency mining, where specialized hardware performs computational work to secure a blockchain.

Does the Telegram app perform real blockchain mining?

The current Telegram experience is best understood as an ecosystem participation and point-accrual system. Users do not need mining hardware, GPUs or ASIC devices to participate.

The term "mining" is used inside the product experience to describe the timed accumulation of APXN Points. However, users should distinguish this from proof-of-work mining performed directly on a blockchain network.

This distinction matters for transparency. A user interacting with a Telegram button is participating in the Apex Network reward system; the action itself is not proof-of-work computation.

Daily Check-In rewards

Apex Network also includes a daily check-in mechanism. This rewards users for returning to the Mini App regularly.

The current seven-day progression starts at 100 APXN Points and increases through the cycle until reaching 700 APXN Points on the seventh day.

Daily check-ins create a second participation layer beyond the 12-hour mining claim. For users, this means regular engagement can matter independently from the timed point accumulation.

Daily Telegram and X tasks

Social participation is another part of the current application. Daily tasks connected to Telegram and X can each provide 100 APXN Points when completed according to the app's current rules.

The project also includes one-time social tasks. These can provide 500 APXN Points per task. The purpose is to connect community growth with the reward experience inside the Mini App.

Some Telegram membership tasks are not based only on a user pressing a button. The application can verify Telegram channel or group membership through Telegram's API before crediting the relevant reward.

How APXN referrals work

Referrals are one of the main mechanics inside Apex Network. A user can invite another person through a referral link. When the referral is valid, the new participant can receive a referral-related starting reward, while the referring user's network can affect mining speed.

Under the current app logic, a valid referred user can receive an additional 1,000 APXN Points when joining through the referral flow.

Active referral mining boost

An active referred friend can increase the referring user's mining rate by 5% of the base mining rate.

The important word is active. In the current logic, a referred user is considered active when that user has made a claim within the previous 24 hours.

This means the referral feature is not simply a count of how many people were invited. The system rewards networks where referred users continue to participate.

Registration rewards

Apex Network also uses staged registration rewards. The amount can depend on the current user-growth stage of the platform.

The current project logic includes a progression of registration rewards such as:

  • 10,000 APXN Points for the earliest qualifying stage.
  • 5,000 APXN Points in a later stage.
  • 2,500 APXN Points as the user base continues to expand.
  • 1,000 APXN Points in a subsequent stage.

Because these rewards are linked to growth thresholds, users should rely on the amount displayed by the live application rather than assume that an older promotional amount is still available.

Country and referral information

The Mini App stores a user's country when the account is created. This information supports ecosystem statistics and features such as displaying country flags alongside referred friends.

This helps the project show the geographic reach of its community without changing the fundamental points mechanics.

Account verification and security

Telegram Mini Apps can receive signed initialization data from Telegram. Apex Network's server-side logic verifies this data rather than blindly trusting identity information coming from the browser.

The verification flow uses Telegram's signed initData and HMAC validation. This is an important security layer because account balances and referral relationships should be associated with verified Telegram identities rather than arbitrary client-side values.

No system is risk-free, but server-side validation reduces the opportunity for simple client-side impersonation or manipulation.

What about wallet linking?

The current user interface contains wallet-related elements, but users should distinguish between a visible interface and a fully persisted wallet-binding feature.

In the current version reviewed for this guide, permanent wallet-address storage is not treated as a completed production feature. For that reason, Apex Network documentation should not tell users that their wallet is permanently linked to their Telegram account unless that functionality is later implemented and verified.

What about Boosts?

The application includes a Boost Store concept, but the current interface marks those options as Soon and the purchase actions are disabled.

This is a good example of the difference between a live feature and a planned feature. The blog will describe boosts as part of future product development until the purchasing and activation logic is actually enabled.

APXN Points and the future token ecosystem

Apex Network's broader roadmap includes a BEP-20 ecosystem on Binance Smart Chain and later network-development milestones. However, the existence of a points balance today does not by itself determine the future market value of APXN, a listing price or an exact point-to-token conversion ratio.

Any conversion rules should come from a future official project announcement and should be clearly documented when finalized.

For this reason, responsible APXN content should avoid statements such as "one point equals one token" or promises of guaranteed value unless the project formally establishes those rules.

Why this approach matters for users

Clear documentation helps users understand what they are doing inside a Web3-related application. It also separates real functionality from expectations about future development.

Today, users can evaluate Apex Network based on concrete mechanics: timed claims, check-ins, tasks, referrals, active-friend boosts and account verification. Future features can then be documented when they become operational.

How to start using the APXN Mini App

  1. Open the official Apex Network Telegram Mini App.
  2. Create or initialize your APXN account through Telegram.
  3. Review your current starting balance and mining rate.
  4. Participate in the 12-hour claim cycle.
  5. Use Daily Check-In when available.
  6. Complete eligible social tasks.
  7. Invite real users through your referral link.
  8. Return regularly so your own account and referral network remain active.

Always use the official links published by Apex Network and be cautious of private messages claiming to offer guaranteed APXN returns, paid account upgrades or requests for seed phrases.

Frequently asked questions
