Authentication Factors and Password Practices

Ethereum documentation explains three authentication categories: something you know such as a password, something you are such as a fingerprint, and something you own such as a security key or authenticator app. Two-factor authentication supplies an extra factor so that a password alone does not grant access. The most common second factor is a randomized six-digit code generated as a time-based one-time password through apps like Google Authenticator.

The same materials note that the seed generating the timed code resides on the user device, functioning as an ownership factor. CISA resources provide tip sheets and additional materials in multiple languages that expand on secure online practices. Both sources present these elements as standard components of account protection strategies discussed across cybersecurity guidance.

Recovery Phrase and Key Handling

Ethereum security guidance states that users should never share the recovery phrase or private keys for any reason. The recovery phrase functions as the master key to the wallet, allowing anyone who obtains it to access all accounts and assets. Private keys operate similarly for individual accounts. The source explicitly notes that no legitimate service, support agent, or website will request these items.

The same passage advises against taking screenshots of seed phrases or private keys and recommends considering a hardware wallet while double-checking transactions before sending. It also suggests setting smart contract spend limits. These points appear under the wallet security heading alongside common scam descriptions and web security practices such as using strong passwords and a password manager.

How does two-factor authentication add protection?

Documentation explains that two-factor authentication requires an additional factor beyond a password. The common implementation uses a randomized six-digit time-based one-time password generated by an authenticator app whose seed is stored on the device, serving as a something-you-own factor.
